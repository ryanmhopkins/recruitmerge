# RecruitMerge Chrome Web Store listing

## Name

RecruitMerge

## Summary

Save LinkedIn candidates to a calm, organized recruiting workspace in one click.

## Detailed description

RecruitMerge helps recruiters and sourcers capture candidate details from LinkedIn without interrupting their workflow.

Open a LinkedIn member profile, select the RecruitMerge extension, choose a job or pipeline, add an optional sourcing note, and save the candidate to your private cloud-synced dashboard.

Key features:

- Detects the name, headline, company, location, and profile URL shown on the active LinkedIn profile
- Organizes candidates by job or pipeline
- Prevents duplicate profile records in your workspace
- Keeps sourcing notes alongside each candidate
- Supports candidate editing, search, filtering, and CSV export in the RecruitMerge dashboard
- Stores candidate records in your private account workspace

RecruitMerge reads only the active LinkedIn profile when you open the extension. Candidate details are sent to RecruitMerge only when you select Save to workspace.

RecruitMerge is an independent productivity tool and is not affiliated with or endorsed by LinkedIn.

## Single purpose

RecruitMerge lets a signed-in recruiter capture selected candidate details from the active LinkedIn profile and save them to an organized private sourcing workspace.

## Permission justifications

### activeTab

Used only when the user opens RecruitMerge on the active LinkedIn profile so the extension can read the visible candidate details for review before saving.

### scripting

Used to run the candidate-detection function in the active LinkedIn tab after the user opens the extension.

### storage

Used to store the user's RecruitMerge authentication session locally so the extension can securely save candidates to the user's own workspace.

### linkedin.com host access

Required to detect the candidate details displayed on LinkedIn member profile pages. RecruitMerge does not read LinkedIn pages in the background.

### Supabase host access

Required to authenticate the user and save the candidate record to RecruitMerge's database after the user selects Save to workspace.

## Data-use disclosures

- Personally identifiable information: email address for account authentication; candidate name and LinkedIn profile URL selected by the user
- Website content: visible candidate details from the active LinkedIn profile
- Authentication information: RecruitMerge session tokens stored locally
- User activity: job or pipeline label and sourcing notes intentionally entered by the user

Data is used only to provide RecruitMerge's candidate capture and workspace features. It is not sold, used for advertising, or transferred for unrelated purposes.
